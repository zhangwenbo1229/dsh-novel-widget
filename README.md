# @xrn1997/dsh-novel-widget

给 DeepSeek Harness（DSH）用的**悬浮阅读挂件**：一个常驻小气泡，点开就是浮在任何界面之上的阅读窗——连续滚动、目录跳章、进度自动回写到书架。

它不自己抓站、不带书源、不做搜索。所有数据都从 **dsh-novel 的 `/novel-api`** 同源读，是把「已经装好的小说插件」变成「随手能翻的一页」。

## 它解决什么

读长篇的时候，看一眼下一章要离开当前界面：切到「小说」面板、找到那本书、翻到那一章，回来还要重新找到刚才在干的活。这个挂件把那一页钉在屏幕上：任何面板之上都在，滚到哪存到哪，关掉再开还在原处。

## 要求

- **必须已安装并启用 [`@xrn1997/dsh-novel`](https://github.com/xrn1997/dsh-novel)**：本挂件只是它的读者，自己没有抓取能力。没装时挂件会明确说「请确认已安装并启用了 dsh-novel」，而不是转圈。
- DSH 宿主带 `@deepseek-ai/dsh-web-app`（挂件挂的是浏览器的 `shell.overlay` 槽）。

## 安装

```powershell
dsh plugin --profile <profile> add @xrn1997/dsh-novel-widget
```

从源码目录安装（`link:`）时**必须先构建**，否则整棵插件树装载失败：

```powershell
cd D:\code\dsh-novel-widget
pnpm install      # prepare 脚本会自动构建 lib/（这一步不能省）
pnpm build        # 需要显式重建时
dsh plugin --profile <profile> add link:D:/code/dsh-novel-widget
```

`pnpm install` 会跑 `prepare: tsdown`，所以「装完没有 `lib/`」这种失败模式不会静默发生——构建不过，安装就不过。

## 功能

- **常驻气泡**：44px 圆点，可拖动，拖过就不算点击。
- **贴边吸附**：松手时离屏幕边缘 40px 以内就吸上去，贴着的那侧圆角收成直角、整体降到 42% 不透明「让开」界面；悬停或用键盘聚焦时回到不透明。存的是「贴哪条边」而不是像素，换个窗口大小仍贴着边。
- **消息气泡形态**：四周圆角 + 一个指向气泡的尖角。浮窗**固定在气泡旁**：气泡在上就往下弹、贴到底边就自动翻到上方，挪气泡它跟着走。
- **移出即缩回**：鼠标移出气泡与浮窗（两者之间那条缝也算一体）后停 0.5 秒自动缩回；打开目录 / 拖动期间不缩回。
- **纯白纸面**：气泡窗口恒为白底黑字，不跟宿主主题走——阅读的对比度由「纸」决定。
- **没有标题栏**：书名 / 章号 / 折叠 / 关闭那一整条都撤了，只有正文 + 底部功能键。高度 280px（约 8–10 行）。关闭靠：鼠标移出、Esc、底部「换一本」。
- **滚动条隐藏**：气泡与目录都不要那根灰杠（滚轮、触控板、键盘照常）。
- **连续滚动**：章节首尾相接，滚到底自动追下一章；两侧各留几章，超出的自动裁掉。
- **目录**：定高虚拟滚动（三千章也不卡），当前章高亮、打开即定位到它；右上角可切**正序 / 倒序**、可**刷新目录**。
- **刷新目录**：带 `refresh=1` 去源站重新拉取（绕过缓存），应付「作者刚补了新章」。刷新后当前读的那一章**按 URL 认**（源站往中间插章会让其后下标全部 +1），正文本缓存全部作废重取，新的章数同步回书架；源站回空目录时保留原目录并如实说明。
- **右键换书**：在气泡上点右键，就地弹出书架列表（当前那本打勾）。
- **书架对账**：在小说面板里删了书，挂件会自己跟上——重新叫出挂件（或切回本页）时重读书架，正在读的那本若已被删除就换到架上剩下的那本。
- **跳章落位**：目录 / 上一章 / 下一章跳到目标章后，自动把该章顶到视口顶端；跳转瞬间内容还没到货时也不会落错（见下）。

## 用法

| 动作 | 结果 |
| --- | --- |
| 点气泡 | 打开 / 收起阅读窗（收起时把进度存一次） |
| 拖气泡 | 挪到别处；松手时贴边就吸附并半透明 |
| 右键气泡 | 弹出书架列表，就地换书 |
| 滚轮 / 拖动滚动条 | 读完本章后自动接下一章 |
| 鼠标移出气泡与浮窗 | 0.5 秒后自动缩回（收起前存一次进度） |
| 底部「目录」 | 目录抽屉，当前章高亮；点任一章跳过去 |
| 抽屉右上角 | 刷新目录（去源站重取）/ 切换正序倒序 |
| 底部「Aa」 | 字号 / 行距 / 栏宽 |
| Esc | 先收抽屉，再关浮窗 |

## 进度是怎么存的

只在**三个关键时机**写回（切章、浮窗失焦、关闭），不随滚动高频写——主面板与挂件可能同时开着同一本书，高频互写会把位置来回拉扯。

比例口径与主面板一致：跨度用**该章自己的渲染高度**，所以两边算出的 `offsetRatio` 同义，切换两边不跳位。

## 三处「量出来的」设计约束（都对应真实故障）

1. **命中判定要量元素的真实矩形，不能用我们写进 CSS 的数值推算**。应用外壳的祖先一带 `transform`（做合成层），它就成为 `position: fixed` 的包含块，窗口被画在「祖先偏移 + 我们给的值」处，而 `clientX/clientY` 是视口坐标——实测差 60px，判定区整体错位，鼠标明明在窗口里却判成已移出。
2. **入场动画只做透明度，不做 transform**。`scale` 会让 `getBoundingClientRect()` 在动画期间返回变形后的框，早期版本据此算出的安全区永远比窗口小约 6%。
3. **「指针离开页面」只认根元素上的 leave**。监听挂在 document 上且走捕获阶段，会把任何后代的 `pointerleave` 都收进来；而滚动正文时浏览器会不断为「从指针下方滚走的段落」派发 pointerleave——不甄别目标的话，滚一下阅读窗就等于「鼠标离开了页面」，窗口自己缩回。

## 跳章为什么要一个显式状态

跳转瞬间目标章的内容往往还没到货（整屏「加载中」占位，每章十几像素），此时内容比容器还矮、根本没有可滚动空间，落位会被夹成 0；等真内容到达（十几像素 → 上千像素），布局完全变了。更麻烦的是：拿这种占位布局去反推当前章，会**把用户刚点的目标章改写掉**（实测「点第 21 章跳到第 18 章」）。

所以跳转是一个显式状态（会话里的 `jumping`）：落定之前滚动回写一律不作数，视图追着布局补落，直到目标章之前那几章都不再是「加载中」；用户一动滚轮/触摸/按键就立刻交还控制权。

## 数据与隐私

- 不联网、不采集：所有请求只打本机 `/novel-api`。
- 本机存储只有 `localStorage['@xrn1997/dsh-novel-widget']` 一个键：气泡位置、浮窗几何、偏好、上次读的那本、开合状态。

## 开发

```powershell
pnpm install
pnpm build        # 构建 lib/（Node 半 + 浏览器半）
pnpm dev          # tsdown --watch
pnpm test         # 常规集
pnpm typecheck    # tsc --noEmit
```

改动生效分两半：浏览器半（`src/client/`）由宿主 HMR 热推；Node 半要重启宿主。

### 契约门（默认跳过）

`src/client/wire.ts` 是 dsh-novel HTTP 形状的**镜像抄本**，抄本会腐烂。唯一能发现「对面改了、挂件静默读空」的是真打本机的契约门：

```powershell
$env:DSH_NOVEL_CONTRACT='1'
$env:DSH_NOVEL_ORIGIN='http://127.0.0.1:12968'   # 可选，缺省就是这个
pnpm test
```

它要求宿主正在跑、dsh-novel 已装、书架上有书；dsh-novel 改契约时那里就该红。

### 结构

```
src/
├── index.ts              Node 半：空插件（只为让插件行能挂上）
└── client/
    ├── index.tsx         浏览器半入口：注册 shell.overlay
    ├── wire.ts           dsh-novel 的 HTTP 契约镜像（零依赖）
    ├── api.ts            读口 + 写口，信封解包与错误分类单点
    ├── reader-session.ts 业务时序（取目录/取章/预取/存进度/刷新目录/跳转协议）
    ├── reader-model.ts   窗口、预取、裁章、切段（纯函数）
    ├── progress.ts       像素 ⇄ 比例（纯函数，与主面板同口径）
    ├── anchor.ts         浮窗相对气泡的锚定位置（纯函数）
    ├── snap.ts           气泡贴边吸附与透明度（纯函数）
    ├── hover.ts          移出即缩回的安全区判据与守望器
    ├── viewport.ts       视口订阅（定位与命中判定共用同一份）
    ├── prefs.ts          偏好与持久化 + 归一化
    ├── state.ts          模块级现场（跨卸载不丢）
    ├── copy.ts           中文文案单点
    ├── styles.tsx        样式层（纸面色 + 宿主 token）
    ├── whale-glyph.ts    鲸鱼字形路径（图标与气泡入口同一份）
    └── views/            Bubble / Shell / ReaderPane / TocDrawer / BookPicker / BookMenu / PrefsBar
```
